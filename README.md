# astrbot-plugin-sleep · 睡觉模拟插件

让 AstrBot 机器人拥有人类般的作息与睡眠状态。可被哄睡、也会打呼，连续被发消息会吵醒。

## ✨ 功能

- **三级睡眠状态机**：`清醒(awake)` → `迷糊(sleepy)` → `睡着(asleep)`
- **可被哄睡**：用户说「快去睡觉」「晚安」「困不困」「早点睡」等，机器人会迷迷糊糊地回应
- **睡着了真的不理人**：进入睡着状态后，普通消息一律不回复（阻止默认 LLM 接话），直到被吵醒
- **连发消息会吵醒**：短时间内连续收到多条消息，会被吵醒并发出「谁啊！吵醒我了！」之类的反应
- **语音直接唤醒**：说「起床」「醒醒」「早上好」即可唤醒
- **命令控制**：`/睡觉` 强制入睡、`/起床` 强制唤醒
- **每会话独立**：群聊、私聊各自独立的作息状态

## ⚙️ 安装

1. 把 `astrbot_plugin_sleep` 文件夹放到 AstrBot 的 `data/plugins/` 目录
2. 在 AstrBot 后台**启用插件**，然后**重启 AstrBot**
3. 完成

## 🎮 使用

### 哄睡话术（触发迷糊状态）
```
快去睡觉
该睡觉
晚安
好晚了
早点睡
困不困
```

### 彻底睡着话术（从迷糊加强到睡着）
```
睡着了吗
快去睡
怎么还不睡
```

### 唤醒话术
```
起床
醒醒
别睡了
早上好
太阳晒屁股
```

### 命令
- `/睡觉` —— 强制进入睡着状态
- `/起床` —— 强制唤醒到清醒状态

## 🔧 配置项

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `wake_msg_count` | `3` | 10 秒内连续收到几条消息会被吵醒 |
| `wake_interval` | `10` | 判定"连续发送"的时间窗口（秒） |

## 📁 文件说明

- `main.py` —— 插件主逻辑（睡眠状态机）
- `metadata.yaml` —— 插件元数据（名称/描述/版本）
- `__init__.py` —— 插件入口标记

## 📌 技术细节

- 使用 `@filter.event_message_type(filter.EventMessageType.ALL)` 拦截全部消息
- 睡着状态通过 `event.should_call_llm(False)` + `event.stop_event()` 阻止默认 LLM 回复
- 状态机按 `event.get_session_id()` 为每个会话维护独立实例
- 命令消息（`/` 开头）在睡眠状态下**不会**被吞，保证 `/找深深`、`/cu` 等命令照常可用
